# 第三阶段执行报告

执行时间：2026-11-18 至 2026-11-19。研究范围为曼哈顿 Citi Bike 站点小时级骑出、骑入、净流出与短期库存风险。本报告只记录实际运行结果。

## 1. 信息边界与实验设计

- 唯一时间键为 UTC 小时；纽约本地时间、UTC 偏移和夏令时标记单独保留。秋季回拨的重复本地小时不混合，正式回测中排除 `dst_ambiguous_collapsed` 行。
- 2024 回测：训练截至 2024-10-31，评价 2024-11；2025 回测：训练截至 2025-10-31，评价 2025-11。评价集从未参与相应模型训练。
- 神经网络用稳定哈希抽取训练集的 1/8，以控制训练资源；历史站点轮廓和面板固定效应使用截止日前全部合法历史数据。2024/2025 神经网络训练行数分别为 1,383,720 和 2,143,092；评价行数分别为 504,015 和 476,511。
- 回测天气使用 Open-Meteo Previous Runs 的固定 48 小时提前量历史预报，不用事后观测天气。2024、2025 年 11 月各 744 个 UTC 小时，模型所用字段均完整。
- 固定日期模型不使用骑行目标滞后，也不使用未来 GBFS 库存；GRU 输入为过去 24 小时的可预知日历、历史轮廓和天气预报序列。因此它是合法的长提前期模型，而不是依赖未发布订单的伪实时模型。
- 所有模型以同一训练/测试边界比较。报告的关系是预测关联，不作因果解释。

## 2. 实际模型

### 历史基准

站点 × 月份 × 星期 × 小时的训练期平均需求；稀疏组合按更宽层级回退。这是所有复杂模型必须超过的基准。

### 面板回归

先用完整训练期站点季节轮廓吸收站点与周期性差异，再对 `log1p(需求) - log1p(轮廓)` 拟合天气/节假日项。系数估计抽取 600,000 行，按纽约本地日期聚类稳健标准误。比较了“天气”和“天气+节假日”两个版本。

### ANN

PyTorch MLP：站点嵌入 16 维，两个隐藏层 128/64，SiLU、0.1 dropout、Softplus 双输出，Poisson 目标，AdamW。basic 训练 3 轮；full 训练 4 轮。full 加入天气和节假日。

### GRU

PyTorch 单层 GRU，隐藏维 64，站点嵌入 16，24 小时外生序列，Softplus 双输出，Poisson 目标，训练 3 轮。不使用最近 24/168 小时真实订单。该约束与 2026-11-26 长提前期预测保持一致。

本地使用 PyTorch 2.11.0+cu128 和 NVIDIA GeForce RTX 4060 Laptop GPU。最终模型 ANN 四轮 Poisson 目标为 -4.4499、-5.3120、-5.3788、-5.4131；GRU 三轮为 -3.2092、-4.8850、-5.1036。

## 3. 严格样本外结果

以下为整月 WAPE（骑出 / 骑入 / 净流出）。

| 模型 | 2024-11 | 2025-11 |
|---|---:|---:|
| 历史轮廓 | .548 / .567 / 1.006 | .516 / .528 / .962 |
| 面板：天气 | .541 / .559 / .985 | .501 / .513 / .944 |
| 面板：天气+节假日 | .528 / .546 / .975 | .486 / .498 / .935 |
| ANN basic | .551 / .569 / .988 | .524 / .537 / .964 |
| ANN full | **.490 / .512** / .988 | **.476 / .490** / .949 |
| GRU 外生序列 | .566 / .582 / 1.010 | .533 / .542 / 1.011 |

ANN full 对骑入/骑出最准确；2025 净流出 WAPE 则是面板完整模型最低。GRU 在不允许偷用近期未发布订单后没有超过基准，故不选作最终固定日期模型。

2025 年感恩节 ±3 天是预先指定的最终模型选择场景，共 110,971 个站点小时。骑入/骑出平均 WAPE：ANN full .646、面板完整 .658、GRU .684、历史轮廓 .887，因此最终固定日期需求模型选择 ANN full。感恩节当天需求较低，ANN 骑出/骑入 WAPE 为 .861/.838，百分比误差会被小分母放大。

ANN full 的 2025 场景结果：工作日 .449/.462，周末 .516/.532，感恩节窗口 .641/.651，极端天气 .784/.780。分站点结果已输出；极低实际需求站点的站点级 WAPE 会异常大，应结合 MAE 和活动量判断。

### 高压力站点排名

2025 整月每小时 Top 10/20 精确率：历史轮廓 .208/.226，面板完整 .209/.226，ANN full .186/.200，GRU .075/.103。ANN 的总量误差最低，但压力排序没有胜过面板/基准；风险排序应保留独立模型或规则，不能仅按 ANN 净流出排序。

### 消融

相对历史轮廓，2025 整月面板天气使骑出/骑入 WAPE 改善约 .015/.015；再加节假日后总改善 .030/.030；ANN full 总改善 .040/.039。ANN basic 反而比基准差约 .008，说明复杂度本身没有带来收益。感恩节窗口中，ANN full 总改善 .242/.240。

## 4. 面板变量解释

2025 完整模型中，相对站点季节轮廓的对数需求：每升高 10°C 与骑出/骑入约 +.047/+ .045 相关，同时二次项为负；降水对数项约 -.257/-.256；雪约 -.119/-.106；每 10m/s 风速约 -.180/-.176；感恩节约 -.384/-.391，次日约 -.434/-.441。感恩节系数换算约为需求下降 31.9%/32.4%，次日约下降 35.2%/35.7%。这些项除“距感恩节天数”外在常用水平显著，但残差 R² 仅约 .043/.042，且不能解释为天气或节日的因果效应。

## 5. 库存风险

ctbk.dev 标签只保留起点小时和目标小时均至少 45 个观测分钟、至少 45 个运行中观测且容量大于零的曼哈顿站点小时。训练 1,949,458 行；严格测试为 2026-10 的 483,348 行。特征来自上一完整小时或 10 月前建立的需求轮廓，目标是下一小时是否曾空车/满桩。

| 风险 | 方法 | Precision | Recall | F1 | TP / FP / FN |
|---|---|---:|---:|---:|---:|
| 空车 | 当前库存规则 | .629 | .682 | **.654** | 36,464 / 21,541 / 17,022 |
| 空车 | 库存+轮廓净流量 | **.934** | .241 | .383 | 12,889 / 906 / 40,597 |
| 空车 | Logistic | .437 | **.965** | .601 | 51,589 / 66,543 / 1,897 |
| 满桩 | 当前库存规则 | .692 | .690 | **.691** | 50,414 / 22,409 / 22,702 |
| 满桩 | 库存+轮廓净流量 | **.940** | .029 | .056 | 2,102 / 135 / 71,014 |
| 满桩 | Logistic | .519 | **.961** | .674 | 70,265 / 65,187 / 2,851 |

简单当前库存规则的 F1 最好；净流量规则精度高但漏报严重；Logistic 召回高但误报多。库存均值仍不等于生产环境最新快照，且真实调度、被抑制需求、未完成借还车和在途车辆不可见。实时生成器已用持久化 GBFS 快照实际跑通 689 个曼哈顿站点，但该快照来自一次手动采集，不能称为持续实时服务。

## 6. 2026 感恩节预测准备

最终模型用 2023-01-01 至 2026-10-31 的合法数据重训：神经网络样本 2,886,868 行，站点映射 828 个。2026-11-18 已用当时的 Open-Meteo 实时预报生成一份**初步**文件：686 个当前站点 × 24 小时 = 16,464 行；预计骑出合计 29,489、骑入 28,137、净流出 1,352。由于预报取得日距目标日八天，这不是最终冻结预测。

程序只允许在纽约当地 11 月 24 或 25 日用 `--status final` 冻结最终预测，并保存生成时间、天气文件及取得时间、模型版本、训练范围和经验误差带。90% 经验绝对误差分位带来自严格的 2025 感恩节 ±3 天回测，骑出/骑入/净流出分别约 4.69/4.79/4.33 辆；它不是具有有限样本覆盖保证的正式 conformal 区间。2026 年 11 月订单尚未发布，当前不能验证实际需求。

## 7. GBFS 自动采集状态

GitHub Actions 仍只有 `workflow_dispatch` 手动事件，未出现真实 `schedule` 事件；Release `gbfs-data` 仍是 3 个源更新时间、7,556 个站点状态行，最后一次为 2026-11-18 13:37 UTC，重复键为零。故结论仍是：采集器、去重和 Release 持久化已手动验证；15 分钟自动调度**未验证、未运行**。

原生 schedule 在公开仓库、默认分支、启用 Actions 且手动运行成功的情况下仍未触发。已准备最低权限的外部调度方案：cron-job.org 每 15 分钟调用现有 workflow dispatch；需仓库所有者创建仅限该仓库、仅 Actions 读写、短期有效的细粒度 Token，并只保存在外部服务密钥栏。必须观察两次相隔约 15 分钟的外部自动运行及 Release 增长后，状态才可改为通过。
